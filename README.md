# Páginas públicas de AgroVaca

Este repositorio existe solo para publicar dos páginas que el App Store exige
que sean accesibles sin iniciar sesión:

- **[Política de privacidad](https://vivianadurant92-ship-it.github.io/agrovaca-privacidad/)** — `index.html`
- **[Soporte](https://vivianadurant92-ship-it.github.io/agrovaca-privacidad/soporte.html)** — `soporte.html`

El código de la aplicación no está aquí: vive en un repositorio privado aparte.

Los dos archivos HTML se **generan** desde el Markdown de ese repositorio, con
`npm run paginas`. No se editan a mano aquí: cualquier cambio hecho
directamente en este repositorio se perdería en la siguiente generación.
